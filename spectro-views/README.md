# Spectro – real-time spectrogram + sound labeling (plain Android Views, no Compose)

Builds on GitHub Actions: push to main (or Actions tab -> Build APK -> Run workflow),
then download the `spectro-debug-apk` artifact and install app-debug.apk on your phone.

Local build (optional): JDK 17 + Android SDK + Gradle 8.14.x, then `gradle assembleDebug`.
